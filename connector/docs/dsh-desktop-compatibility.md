# DeepSeek Harness 桌面兼容

连接器 **0.2.21** 支持官方 Windows **DSH 0.2.2-rc.5**，同步适配事件连接、余额组件与升级助手 0.1.7。安装前在 DSH 的「应用 → 关于」核对宿主版本，安装后在「插件 → DSHOS Link」核对连接器版本。[官方发行说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.5)

在 rc.5 桌面的 DeepSeek 账号模式下，连接器先精确合计同币种的充值余额与赠金，再把结果传给手机。正余额向下取分，负余额四舍五入到分，不足一分的欠款显示为 −0.01。既有手机协议只接受数字，正余额不足一分时显示 0.00。读取失败时手机显示查询状态。

首次配对还需要电脑先取得受支持的局域网地址（常用 Wi‑Fi/有线网络下的 `10.x`、`172.16–31.x`、`192.168.x`）。云配对不要求手机和电脑在同一网络，但这不等于没有本地地址也能完成首次配对。配对码输入框暂不可输入时，输入框旁会直接说明原因；没有可用地址或网络信息读取失败时，可点「重新检测网络」立即重试（约 10 秒节流），后台仍会定期自动检测。

| 电脑当前组合 | 如何更新 |
| --- | --- |
| DSH 0.2.2-rc.5 + 旧连接器 | 正常退出 DSH，用命令行升级，同时更新连接器和对应余额组件。 |
| DSH 0.2.2-rc.5 + 连接器 0.2.21 | 可继续使用；在插件页核对版本及连接状态。 |
| 其他已识别的 DSH 版本 | 完整名单见包内 `dshosUpgrade.hosts`。页面内升级还需要宿主接口、升级助手及空闲检查通过；识别宿主不等于支持页面内升级。 |

```powershell
npx --yes @dshos-link/connector@latest upgrade
```

当前已获审手机版兼容基线是 **1.1.2/build192/1001054（API26）**；1.1.1/build187 为历史兼容与升级起点。原送审同版测试签名包已验证新插件和新服务的配对、LAN 收发、余额和重开原绑定。市场实际可下载版本以应用市场页面为准。187→192 同测试签名覆盖已验证保留绑定和数据，不冒充华为市场升级结果。

Pro 原绑定跨网和恢复复用未受影响的历史真机证据，最终组合本轮未重新进行物理跨网测试。rc.5 的历史会话导入由 DSH 提供，本插件未新增导入入口。
