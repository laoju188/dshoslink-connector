# 连接器更新

在 DSH 的「插件 → DSHOS Link」查看连接器版本和更新提示。页面显示更新按钮，且当前 DSH 和升级助手支持时，可以从页面更新。开始前请先保存工作，并等电脑上的任务完成。

连接器 `0.2.21` 随包提供升级助手 `0.1.7`，支持从上一版助手（含 0.2.16 分发的 0.1.5 和 0.2.19/0.2.20 分发的 0.1.6）迁移并保留升级记录。页面内安装支持 DSH 0.2.1-rc.3、0.2.1-rc.5、0.2.2-rc.1、0.2.2-rc.2、0.2.2-rc.3 和 0.2.2-rc.5。如果已经把 DSH 升到 `0.2.2-rc.5`、连接器仍是旧版，请完全退出 DSH，在 PowerShell 运行以下命令，让安装工具同时更新连接器和对应的余额组件。

0.2.21 修复更新器回滚：更新中连接器被移除后，若宿主在重载窗口暂时没有 HMR 服务，恢复模式也能安装回缓存的上一版，不再留下“插件标签还在、设置页空白”的状态。升级到 0.2.21 本身请使用完整安装/升级命令，因为执行这次更新的仍是旧助手 0.1.6。

```powershell
npx --yes @dshos-link/connector@latest upgrade
```

更新后重新打开 DSH，在插件页核对连接器版本，再从手机打开原会话检查连接。原绑定可以继续使用。

从本仓库自行构建的版本，请保留原来的完整安装包供回退。页面内更新会核对当前安装来源和回退包，支持条件以插件提示为准。
