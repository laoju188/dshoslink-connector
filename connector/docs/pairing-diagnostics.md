# 配对诊断

在 DSH 的「插件 → DSHOS Link」查看当前连接阶段和提示。配对码尚未被接收时，确认手机上的码仍有效，电脑插件页可以提交。电脑端显示等待确认时，回手机核对并确认这台电脑。

配对诊断使用有限的连接阶段、错误类别、耗时和版本信息。0.2.15 在服务支持时会进一步区分准备保存目录、取得锁、读取配对资料和解密失败等阶段。公开报告问题时，可以说明插件版本、卡住的步骤和界面提示，请隐去配对码、账号信息和私密日志。

在插件页底部可以关闭「帮助改进配对体验」，停止自动诊断上传。手动关闭的选择在重启和升级后保留。点击「发送连接反馈」是一次主动反馈，必要的配对登记仍按正常流程处理。
